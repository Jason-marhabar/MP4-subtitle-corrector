# GUI 与业务调度模块 接口对接文档

> 本文档写给 **任务2（业务调度 & 多线程控制）** 的同学。
> 约定双方：任务1（GUI）↔ 任务2（业务调度）。任务3/4 的 FFmpeg、ASR 模块由调度层调用，不直接接触 GUI。

---

## 1. 通信模型

```
┌─────────────────────┐                    ┌──────────────────────────┐
│  GUI（任务1）        │                    │  业务调度层（任务2）       │
│  view/main_window   │   GuiSignals       │  controller/scheduler    │
│                     │ ──────────────────▶│  （在子线程/线程池中        │
│  用户点击按钮        │                    │   调用 FFmpeg、ASR 模块）  │
│  → emit 信号         │   WorkerSignals    │                          │
│                     │ ◀──────────────────│  干活进度/结果            │
│  收到信号更新界面     │                    │  → emit 信号              │
└─────────────────────┘                    └──────────────────────────┘
```

**三条铁律（违反会导致卡死或崩溃）：**

1. GUI 绝不直接调用 FFmpeg / Whisper / 字幕模块，只发 `GuiSignals`。
2. 调度层绝不在子线程里直接操作 GUI 控件，只发 `WorkerSignals`。
3. 双方只通过 `view/signals.py` 里定义的两类信号通信，信号名和参数**不得改动**；如需改动，双方必须同步确认。

---

## 2. 信号接口定义

所有信号定义在 `view/signals.py`。调度层拿到两个信号对象后，**连接即可**，不需要 import 其他 GUI 代码。

### 2.1 GuiSignals —— GUI 发出，调度层接收（干活指令）

| 信号 | 参数 | 触发时机 | 调度层该做什么 |
|---|---|---|---|
| `start_requested` | `list` | 用户点击「开始」 | 启动后台线程，开始处理任务 |
| `pause_requested` | 无 | 用户点击「暂停」 | 暂停正在处理的任务（可选支持） |
| `resume_requested` | 无 | 用户点击「继续」 | 恢复暂停的任务 |
| `stop_requested` | 无 | 用户点击「停止」 | 停止当前任务，退出线程 |
| `clear_requested` | 无 | 用户点击「清空列表」 | 可忽略（仅 GUI 清空本地列表） |

**`start_requested` 参数格式（重点）**：一个 list，每个元素是一个二元组：

```python
tasks = [
    ("D:/video/a.mp4", "D:/output"),   # (输入文件绝对路径, 输出目录绝对路径)
    ("D:/video/b.mp4", ""),            # 输出目录为空串 "" 表示「用源文件同目录」
]
```

### 2.2 WorkerSignals —— 调度层发出，GUI 接收（进度/结果回传）

| 信号 | 参数 | 触发时机 | 说明 |
|---|---|---|---|
| `log` | `(str, str)` | 任意时刻 | 参数1=级别（`info`/`warning`/`error`），参数2=日志内容 |
| `task_progress` | `(int, str, int)` | 处理中 | 参数1=任务索引，参数2=当前阶段文字，参数3=百分比 0~100 |
| `task_finished` | `(int, str, str)` | 单任务完成 | 参数1=任务索引，参数2=输出 mp4 绝对路径，参数3=输出 srt 绝对路径 |
| `task_error` | `(int, str)` | 单任务失败 | 参数1=任务索引，参数2=错误信息 |
| `all_finished` | 无 | 全部结束 | 无论成功/失败/停止，最终都要发一次 |

---

## 3. 参数约定（必须遵守）

| 约定 | 说明 |
|---|---|
| **任务索引 task_id** | 与 `start_requested` 传入的任务列表**下标一致，从 0 开始**。GUI 按这个索引定位表格行。 |
| **输出目录为空串** | `""` 表示「使用源文件同目录」，调度层需自行解析为 `os.path.dirname(输入文件)`。 |
| **路径编码** | 全部使用 `str`，Windows 下可能是中文路径，FFmpeg 调用时注意编码（UTF-8）。 |
| **进度百分比** | 0~100 的整数。不要过于频繁地发（例如每阶段发一次，或每 5% 发一次即可，避免界面卡顿）。 |
| **输出 srt 编码** | 最终 srt 必须是 UTF-8 编码（由任务4 保证，调度层转发即可）。 |

---

## 4. 接入步骤（调度层怎么写）

### 第 1 步：构造方法接收两个信号对象

```python
from view.signals import GuiSignals, WorkerSignals


class RealScheduler:
    def __init__(self, gui_signals: GuiSignals, worker_signals: WorkerSignals):
        self.gui_signals = gui_signals
        self.worker_signals = worker_signals

        # 连接 GUI 发出的信号
        self.gui_signals.start_requested.connect(self._on_start)
        self.gui_signals.stop_requested.connect(self._on_stop)
        self.gui_signals.pause_requested.connect(self._on_pause)
        self.gui_signals.resume_requested.connect(self._on_resume)
        # clear_requested 可忽略

        self._thread = None
```

### 第 2 步：在 main.py 里接入

```python
# main.py —— 联调时只需改这一处
from controller.real_scheduler import RealScheduler

scheduler = RealScheduler(window.gui_signals, window.worker_signals)
window._scheduler = scheduler
```

### 第 3 步：收到 start 后，在子线程里干活

**耗时操作（FFmpeg、Whisper）必须放在子线程**，主线程只负责发信号和收信号，否则界面会卡死。

## 5. 真实调度器完整骨架（可直接改）

```python
# -*- coding: utf-8 -*-
"""真实业务调度器骨架（任务2）
在子线程中按顺序调用 FFmpeg 模块（任务3）和 ASR 字幕模块（任务4）。
联调时把下面 TODO 处替换为真实的模块调用即可。
"""

import os

from PyQt6.QtCore import QThread

from view.signals import GuiSignals, WorkerSignals


class RealScheduler:
    def __init__(self, gui_signals: GuiSignals, worker_signals: WorkerSignals):
        self.gui_signals = gui_signals
        self.worker_signals = worker_signals
        self._thread = None

        self.gui_signals.start_requested.connect(self._on_start)
        self.gui_signals.stop_requested.connect(self._on_stop)
        self.gui_signals.pause_requested.connect(self._on_pause)
        self.gui_signals.resume_requested.connect(self._on_resume)

    def _on_start(self, tasks):
        if self._thread and self._thread.isRunning():
            self.worker_signals.log.emit("warning", "已有任务在处理中")
            return
        self._thread = _ProcessWorker(tasks, self.worker_signals)
        self._thread.finished.connect(self._on_thread_finished)
        self._thread.start()

    def _on_stop(self):
        if self._thread and self._thread.isRunning():
            self._thread.stop()

    def _on_pause(self):
        if self._thread and self._thread.isRunning():
            self._thread.pause()

    def _on_resume(self):
        if self._thread and self._thread.isRunning():
            self._thread.resume()

    def _on_thread_finished(self):
        self.worker_signals.all_finished.emit()


class _ProcessWorker(QThread):
    """后台线程：逐个任务走完整流程"""

    def __init__(self, tasks, signals, parent=None):
        super().__init__(parent)
        self._tasks = tasks
        self.signals = signals
        self._stop = False
        self._pause = False

    def stop(self):
        self._stop = True
        self._pause = False

    def pause(self):
        self._pause = True

    def resume(self):
        self._pause = False

    def _check_control(self):
        """暂停/停止检查：在阶段之间调用"""
        while self._pause and not self._stop:
            self.msleep(100)
        return self._stop

    def run(self):
        for idx, (input_path, out_dir) in enumerate(self._tasks):
            if self._check_control():
                self.signals.log.emit("warning", "已停止，剩余任务未处理")
                break

            fname = os.path.basename(input_path)
            out_dir = out_dir or os.path.dirname(input_path)  # 空串→源文件目录

            try:
                self.signals.log.emit("info", f"开始处理：{fname}")

                # ---------- 阶段1：提取音频（任务3 FFmpeg） ----------
                if self._check_control():
                    break
                self.signals.task_progress.emit(idx, "提取音频", 10)
                # audio = ffmpeg.extract_audio(input_path)  # TODO 调用任务3模块

                # ---------- 阶段2：音视频封装（任务3） ----------
                self.signals.task_progress.emit(idx, "音视频封装", 30)
                # out_mp4 = ffmpeg.remux(input_path, out_dir)  # TODO

                # ---------- 阶段3：Whisper 识别（任务4） ----------
                self.signals.task_progress.emit(idx, "Whisper 识别", 60)
                # raw_srt = asr.transcribe(audio)  # TODO 调用任务4模块

                # ---------- 阶段4：字幕校正（任务4） ----------
                self.signals.task_progress.emit(idx, "字幕校正", 85)
                # out_srt = subtitle.correct(raw_srt, out_dir)  # TODO

                # 输出路径（由上面真实模块返回，这里仅示意）
                base = os.path.splitext(fname)[0]
                out_mp4 = os.path.join(out_dir, base + "_矫正.mp4")
                out_srt = os.path.join(out_dir, base + ".srt")

                self.signals.task_progress.emit(idx, "完成", 100)
                self.signals.task_finished.emit(idx, out_mp4, out_srt)
                self.signals.log.emit("info", f"[{fname}] 处理完成")

            except Exception as e:
                # 单个任务出错不中断整个队列，发错误信号继续下一个
                self.signals.task_error.emit(idx, str(e))
                self.signals.log.emit("error", f"[{fname}] 失败：{e}")

        if not self._stop:
            self.signals.log.emit("info", "全部任务处理完毕")
```

## 6. 线程安全铁律（重点）

- **子线程里禁止碰任何 GUI 控件**（表格、进度条、文本框……）。只能 `emit` 信号，让 GUI 自己在主线程更新。
- **不要让 GUI 的信号处理函数里做耗时操作**。例如调度层的 `_on_start` 里只做「创建线程 + start」，不能直接跑 FFmpeg。
- 单个任务失败要用 `task_error` 上报，并继续处理下一个任务，**不要让整个队列崩掉**。
