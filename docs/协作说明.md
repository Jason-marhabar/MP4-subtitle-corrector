# 组内协作说明（克隆后必读）

## 一、队友第一次使用（3 步）

```bat
:: 1. 克隆
git clone <仓库地址>
cd my_app

:: 2. 一键装环境（自动创建 venv、装依赖、配镜像、下载 seconv、自检）
install_env.bat

:: 3. 后续每次工作前设置环境变量
set_env.bat
```

**前置要求**：
- Python 3.10/3.11（安装时勾选 "Add to PATH"）
- FFmpeg（把 `bin` 加入 PATH）
- 若要用 GPU：按 `README.md` 的 GPU 章节再装 CUDA 12 运行库

装完自检：

```bat
venv\Scripts\python.exe scripts\doctor.py --deep
```

## 二、仓库里**没有**什么（以及为什么）

仓库只含**源码与文档（37 个文件、约 334 KB）**。以下内容被 `.gitignore` 排除，
需要各自在本地生成——请**不要**试图提交它们：

| 排除项 | 体积 | 为什么排除 | 怎么获得 |
|---|---|---|---|
| `venv/` | 2.1 GB | 与机器绑定，且平台相关 | `install_env.bat` 重建 |
| `.hf/` | 3.5 GB | Whisper 模型缓存，各人首次运行自动下载 | 首次转写时自动下载 |
| `.pipcache/`、`.tmp/` | 2.6 GB | pip 缓存与 CUDA wheel | 自动生成 |
| `tools/` | 132 MB | seconv.exe（子板编辑工具） | `install_env.bat` 自动下载并校验 SHA256 |
| `test.mp4` | 15 MB | 测试素材，体积大 | 测试时自备视频 |
| `test_output/`、`logs/` | ~96 MB | 运行产物 | 运行时生成 |
| `__pycache__/`、`*.pyc` | — | 编译缓存 | 自动生成 |

**注意**：仓库里没有测试视频。要跑验证脚本（`acceptance.py`、`test_pipeline.py`），
需自己放一个 `test.mp4` 到项目根目录。第一个视频会触发模型下载（small 464MB /
large-v3 3GB），请预留时间与磁盘。

## 二之二、被排除的内容会有问题吗？（逐项实测结论）

**结论：不会。这 7GB 里没有任何"不可替代"的内容。** 逐项验证：

| 排除项 | 缺失后能否恢复 | 验证方式 | 风险 |
|---|---|---|---|
| `venv/` 2.1GB | ✅ 可重建 | `install_env.bat` 自动创建并装依赖 | 无 |
| `.hf/` 3.5GB 模型 | ✅ 可下载 | 本项目实测经 `hf-mirror.com` 成功下载 tiny/small/large-v3 | 低（依赖 `HF_ENDPOINT`） |
| `.pipcache/` 1.3GB | ✅ 可重下 | pip 自动重建 | 无 |
| `.tmp/` 1.3GB（含 CUDA wheel） | ✅ 可重下 | 清华镜像 63s 下完 553MB 的 cublas | 低 |
| `tools/` 132MB seconv | ✅ 自动下载，**且缺失也能跑** | 实测移走后：只记一行日志、保留原文件、字幕仍有效 | **极低（优雅降级）** |
| `test_output/` 96MB | ✅ 运行时生成 | 产物，无保留价值 | 无 |
| `test.mp4` 15MB | ❌ **无替代** | 仓库含 `test.srt` 供参考，但无法复现验证 | **中（自备视频即可）** |

### 两个需要**手动一步**的项（`install_env.bat` 不会自动装）

不在 `requirements.txt` 里是**刻意设计**，避免给所有人强加 GB 级依赖：

| 项 | 谁需要 | 怎么装 |
|---|---|---|
| **CUDA 12 运行库**（约 1.3GB） | 想用 GPU 的人 | 见 `README.md` 的 GPU 章节（清华镜像 + `--no-deps`） |
| **PySide6** | 第一板块做 GUI 的人 | `pip install PySide6 -i https://mirrors.aliyun.com/pypi/simple/` |

**核心功能（出字幕 + 批量调度）只需 `install_env.bat`，不需要上面两项。**

### "干净克隆"完整性已验证

`scripts/verify_clean_clone.py` 检查新克隆的可运行性，实测结论：

```
[OK] PyQt6 / PySide6 / torch —— 可选依赖，代码用 try/except 包裹，缺失不影响核心
[OK] ctranslate2 / faster_whisper / numpy —— 已在 requirements.txt 声明
[OK] AsrEngine 加载成功（faster-whisper 不依赖 torch；本机实测未装 torch 也能转写）
[OK] 无 Qt 时导入不报错，BatchScheduler 仍可用（纯标准库）
[OK] seconv 缺失时优雅降级：保留原文件、仍可解析、未抛异常
```

随时可自查：

```bat
venv\Scripts\python.exe scripts\verify_clean_clone.py
```

### 唯一真正的缺口

**`test.mp4` 没有替代品。** 队友无法复现我们引用的实测数据
（"起点对齐 98%"等）。三种处理方式：

1. **各人自备视频**（推荐）：更贴近真实使用，但无法逐字复现我们的数字
2. **Git LFS**：把 15MB 视频纳入仓库（Gitee/GitHub 都支持）
3. **网盘 + README 链接**：最省事

如果汇报或验收需要他人复现数据，建议选 2 或 3。

## 三、给各板块的接入指引

### 第一板块（GUI）
- 调度层已提供 Qt 适配层，直接用 `controller/qt_worker.py` 的 `SchedulerWorker`
- 信号：`jobUpdated` / `progressChanged` / `logMessage` / `batchFinished` / `failed`
- **不要自己起线程**，它会与调度层的线程池叠加
- 接入建议见 `docs/第二板块-模块说明.md` 的「给第一板块的接入建议」
- 需要先装 PySide6：
  ```bat
  venv\Scripts\python.exe -m pip install PySide6 -i https://mirrors.aliyun.com/pypi/simple/
  ```

### 第三板块（FFmpeg）
- remux 已实现并验证：`model/pipeline.py` 的 `remux_mp4()`
- **关键结论**：`-c copy` 对时间轴零影响（逐帧比对 2702/2702 完全一致），
  **不要重编码**；音频标准化对字幕对齐无帮助
- 注意 `model/ffmpeg_processor.py` 里 `audio_normalize=True` 会把音频重采样到
  96kHz（已改用 `-ar 44100` 修正），改动前先看 `docs/第四板块-探针实验结论.md`

### 第五板块（测试）
可直接复用的测试资产：
- `scripts/test_subtitle_checks.py` —— 字幕校验器自测，9 个用例，可直接当用例原型
- `scripts/test_scheduler.py` —— 调度层测试，30 个用例，覆盖批量/取消/失败隔离
- `scripts/check_srt.py` —— 可进 CI 的字幕质量门禁（退出码分层）
- `scripts/audit_continuous.py` —— 连续语流鲁棒性审计

**推荐把 `check_srt.py` 接入 CI**：退出码 0=干净 / 1=有 ERROR / 2=仅 WARN。

### 第六板块（工程化/打包）
需要注意的点：
- 依赖安装有两个必踩的坑（已固化进 `install_env.bat`）：
  `PIP_CACHE_DIR` 必须重定向，否则 pip 卡在 Building wheel
- PyInstaller 打包需带上的非 pip 资源：
  - `tools/seconv/seconv.exe` + `libSkiaSharp.dll` + `libHarfBuzzSharp.dll`（约 94 MB）
  - FFmpeg 可执行文件
  - Whisper 模型（3 GB，建议首次运行时下载而非内嵌）
- `model/gpu_env.py` 会在运行时自动定位 CUDA 库，打包后需确认路径仍有效

## 四、提交规范建议

```bat
git add <文件>
git commit -m "板块: 简述改动"
git push
```

提交信息前缀建议用板块名，便于定位：`model:` / `controller:` / `view:` / `scripts:` / `docs:`

**提交前自查**（避免把大文件或敏感内容推上去）：

```bat

```

说明 `.gitignore` 被破坏了，**先修好再提交**。

## 五、常见问题

**Q：克隆后跑起来报 `ModuleNotFoundError: faster_whisper`？**
A：没装依赖。运行 `install_env.bat`。

**Q：`venv` 是别人机器上的路径，报 `No Python at ...`？**
A：venv 不该被提交。删除后重建：`rmdir /s venv` 然后 `install_env.bat`。

**Q：模型下载卡住？**
A：确认设了 `HF_ENDPOINT=https://hf-mirror.com`（`set_env.bat` 已包含）。

**Q：GitHub 直连超时推不上去？**
A：见下节。

**Q：环境莫名其妙坏了？**
A：先跑 `venv\Scripts\python.exe scripts\doctor.py`，它会指出问题并给出修复命令。
