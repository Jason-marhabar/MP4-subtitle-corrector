## 四、核心模块详解

### 4.1 真实业务调度器 `controller/real_scheduler.py`

**文件大小**：约 370 行

#### 主要功能

| 功能 | 说明 |
|---|---|
| **多线程执行** | 基于 `QThread + QMutex`，线程安全，界面零卡顿 |
| **任务队列** | 支持批量导入多个 MP4，逐个排队处理 |
| **四阶段流程** | 提取音频 → 音视频封装 → Whisper 识别 → 字幕校正 |
| **精细进度** | 每阶段内分20步更新，进度条平滑递增 |
| **暂停/继续** | 线程安全的暂停控制，随时可暂停继续 |
| **停止** | 支持中途停止，剩余任务标记为"已停止" |
| **异常捕获** | 单任务失败不影响整个队列，支持配置失败即停止 |
| **配置接入** | 从 AppConfig 读取调度参数 |
| **信号对接** | 严格遵守 `view/signals.py` 接口契约 |

#### 技术亮点

- **QMutex + QMutexLocker** 保证线程安全，避免竞态条件
- **`TaskStoppedError` 异常** 用于优雅跳出深层嵌套的处理流程
- **进度权重分配**：四阶段分别占 25%/15%/35%/25%（Whisper最重）
- **输出目录三级优先级**：GUI 指定 > 配置默认值 > 源文件同目录

### 4.3 自定义异常体系 `model/exceptions.py`

**文件大小**：约 400 行

#### 异常继承树

```
AppBaseError（根异常）
├── ConfigError              配置错误
│   ├── ConfigSaveError
│   └── ConfigLoadError
├── TaskError                任务调度错误
│   ├── TaskStoppedError
│   ├── TaskQueueFullError
│   ├── TaskNotFoundError
│   └── TaskAlreadyRunningError
├── FFmpegError              FFmpeg 错误（供3号使用）
│   ├── FFmpegNotFoundError
│   ├── FFmpegProcessError
│   ├── InvalidMediaError
│   ├── AudioExtractError
│   └── RemuxError
├── ASRError                 语音识别错误（供4号使用）
│   ├── ModelNotFoundError
│   ├── TranscribeError
│   └── AudioTooShortError
└── SubtitleError            字幕处理错误（供4号使用）
    ├── InvalidSRTError
    └── SubtitleEditError
```

#### 每个异常包含

- **`error_code`**：数字错误码（1xxx配置 / 2xxx调度 / 3xxx FFmpeg / 4xxx ASR / 5xxx字幕）
- **`user_message`**：面向用户的友好错误提示
- **`details`**：详细技术信息（用于日志调试）

#### 设计初衷

3号和4号的底层模块可以直接抛出这些异常，调度层统一捕获后：
- 给 GUI 展示用户友好的中文提示
- 在日志里输出详细的技术信息便于排错
- 根据异常类型决定是否继续处理下一个任务

## 五、与其他模块的对接方式

### 5.1 与1号（GUI）对接 ✅ 已完成

**对接依据**：`view/signals.py` + `docs/接口对接文档.md`

**通信模型**：
```
GUI  ──GuiSignals──▶  调度层
GUI  ◀──WorkerSignals──  调度层
```

**GUI → 调度层**（5个信号）：
- `start_requested(list)`：开始处理，参数为任务列表
- `pause_requested()`：暂停
- `resume_requested()`：继续
- `stop_requested()`：停止
- `clear_requested()`：清空（调度层忽略）

**调度层 → GUI**（5个信号）：
- `log(str, str)`：日志输出
- `task_progress(int, str, int)`：任务进度（索引、阶段、百分比）
- `task_finished(int, str, str)`：任务完成（索引、输出MP4、输出SRT）
- `task_error(int, str)`：任务失败（索引、错误信息）
- `all_finished()`：全部结束

> 详细说明见 `docs/接口对接文档.md`

### 运行 GUI 程序

```bash
pip install -r requirements.txt
python main.py
```

操作步骤：
1. 点击「选择 MP4 文件」添加文件
2. （可选）选择输出目录
3. 点击「开始」
4. 观察进度、日志
5. 可随时暂停/停止

```python
from model.config import AppConfig

config = AppConfig()  # 单例
config.set("whisper.model_size", "small")
print(config.whisper_model_size)
config.save()  # 保存到文件
```
